Dot eBay pilot privacy

This private, one-time pilot uses your eBay sign-in and reads your saved searches and the first page of your watched listings to confirm access. Your eBay password is entered only on eBay. The pilot does not purchase, bid, send offers, change your lists, or use the data for marketing.

The pilot shows only counts and short status information to the browser that started the test. It does not persist your saved searches, watched listings, authorization code or user tokens. Expiring cookies bind the request to your browser and carry the count-only result; the result is cleared when displayed. The server keeps its eBay application credentials separately in restricted hosting configuration.

The application does not log request contents or API response contents. Like most online services, eBay and the hosting provider may process transient request and security metadata under their own policies. You can revoke application access in your eBay account settings. For questions about this private pilot, contact the project owner who provided your access code.
